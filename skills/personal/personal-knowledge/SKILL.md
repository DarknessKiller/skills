# Personal Knowledge

Use Blinko as the personal memory layer.

1. Search Blinko with the user's terms and likely synonyms. This prevents duplicate notes.
2. Summarize only personal facts supported by Blinko. IF nothing matched: say so.
3. IF the user asks to remember something: save one concise Blinko note. Use `type: todo` only for tasks; otherwise default to `blinko`.

Completion: the search result is supported by Blinko or "nothing matched" is stated, duplicate-saving was avoided, and any written note or ambiguity is named.
